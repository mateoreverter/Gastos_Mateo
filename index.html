Agregar gasto

Esta versión guarda automáticamente las nuevas cargas en este navegador. No modifica el Excel original ni sincroniza entre dispositivos.
Podés usar + − × ÷ con + - * / y paréntesis. Enter calcula.
Carga múltipleAl guardar, mantiene fecha, moneda y medio de pago; limpia descripción, monto y categoría para cargar el siguiente.

Las cargas locales se suman a los gráficos del dashboard. Para cargar varios gastos del mismo período, activá Carga múltiple. Podés exportarlas a JSON para tener una copia.

Agregar movimiento de ahorro

Podés sumar o restar ahorro. La carga se guarda en este navegador y actualiza los KPIs, gráficos y tabla de Ahorros.

PER2A, BCAHA, BCMMA, S28N5 y ESTRA1A se reconocen automáticamente.

Para restar, ingresá el monto en positivo y elegí “Restar ahorro”; el dashboard aplica el signo automáticamente.

Agregar nuevo regalo

El regalo y su estado de pagos quedan guardados en este navegador y permanecen totalmente separados de tus gastos personales.

La tabla se genera automáticamente con una columna por cuota. Después podés marcar pagos tocando cada celda.

Administrar datos

Los cambios de esta sección quedan guardados en este navegador. Los datos originales del Excel no se sobrescriben: cuando borrás algo del Excel, el dashboard lo oculta y después podés restaurarlo.
